# System Sound Map

A reference of all system sound files that RootTone can replace.
Paths are relative to `/system/media/audio/`.

## UI Sounds (`ui/`)

| File | Description |
|------|-------------|
| `Lock.ogg` | Screen lock |
| `Unlock.ogg` | Screen unlock |
| `camera_click.ogg` | Camera shutter |
| `camera_focus.ogg` | Camera focus |
| `VideoRecord.ogg` | Video recording start |
| `VideoStop.ogg` | Video recording stop |
| `LowBattery.ogg` | Low battery warning |
| `ChargingStarted.ogg` | Charging connected |

## Keyboard Sounds (`ui/`)

| File | Description |
|------|-------------|
| `KeypressStandard.ogg` | Standard key press |
| `KeypressSpacebar.ogg` | Spacebar |
| `KeypressDelete.ogg` | Delete/backspace |
| `KeypressReturn.ogg` | Enter key |
| `KeypressInvalid.ogg` | Invalid input |

## Notifications (`notifications/`)

| File | Description |
|------|-------------|
| `default_notification.ogg` | Default notification sound |

## Ringtones (`ringtones/`)

| File | Description |
|------|-------------|
| `default_ringtone.ogg` | Default ringtone |

---

> Note: Exact filenames may vary by device manufacturer and Android version.
> RootTone detects available files at runtime.
